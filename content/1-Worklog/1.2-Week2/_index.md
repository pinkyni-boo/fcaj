### Week 2 Objectives:

* Master the architecture and operating model of AWS's most important compute and storage services.
* Successfully deploy a virtual server and manage cloud-based data storage hands-on.
* Build a security mindset through identity management and access control practices.

### Week 2 Achievements:

* Completed and summarized the theoretical knowledge from the YouTube lecture videos.
* Gained the ability to independently deploy, perform basic network configuration, and connect successfully to Amazon EC2 virtual servers.
* Understood and applied Amazon S3 storage concepts, including access control configuration to protect data, which is an important foundation for the file upload component of the CloudDoc project.
* Built a solid understanding of AWS IAM and can independently configure roles and policies to secure project resources.
