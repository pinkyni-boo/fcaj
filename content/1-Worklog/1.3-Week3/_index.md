### Week 3 Objectives:

* Build a mindset for designing isolated virtual networks in the cloud environment.
* Connect previously learned services such as EC2 and S3 into a complete and secure network infrastructure.
* Master the principle of least privilege to optimize system security.

### Week 3 Achievements:

* Successfully set up an isolated virtual network environment (VPC) with full routing components such as route tables and an internet gateway.
* Smoothly operated EC2 servers and S3 storage inside the network infrastructure that was self-configured.
* Established a strict IAM permission model and maintained clear control over who can access which services.
* Developed a deep understanding of and consistently applied the core security principle of least privilege to protect project resources.
