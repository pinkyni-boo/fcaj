### General feedback

After completing the internship in the FCAJ program, I consider it a valuable experience both technically and professionally. The program did not stop at assigning a project. It created an environment where students could learn cloud fundamentals, attend technology workshops, work on a real project, and improve collaboration skills.

For me, the most valuable part was the transition from studying isolated topics to thinking in terms of product building. While working on CloudDoc, I did not only implement interfaces. I also had to understand metadata, user flows, backend integration, and AWS-oriented architecture. That made the internship much more practical and meaningful.

**1. Learning and working environment**

The program created a structured but open learning environment where students could ask questions, experiment, and improve through feedback. I especially appreciated the combination of AWS fundamentals and project work, because it kept the learning experience connected rather than fragmented.

**2. Mentor and team support**

The mentor and supporting team were particularly helpful during important stages such as problem clarification, technical direction, progress review, and integration support. I appreciated that explanations often included the reasoning behind the technical choice instead of only the final answer.

**3. Project relevance**

CloudDoc was highly relevant to my major because it allowed me to work deeply on frontend while also expanding into backend and cloud-related thinking. It was a strong internship project format because it included user experience, metadata, storage, moderation, and system architecture concerns in one product.

**4. Learning value**

I learned much more than interface coding. I developed a better understanding of metadata design, presigned URL-based upload flow, the difference between storing files and managing document data, and the way frontend must coordinate with backend to create a complete user experience. The workshops also widened my view of GenAI, CloudFront, observability, and system modernization.

### What I appreciated most

- Working on a project with clear practical value instead of only isolated labs.
- Learning both breadth and depth through cloud fundamentals plus project execution.
- Improving self-learning, technical discussion, and cross-role collaboration.

### Suggestions for improvement

**1. Earlier project-document standardization**

It would help future teams if business flow, API contracts, environment setup notes, and implementation checklists were standardized earlier. This would make integration smoother, especially when moving from mock data to real APIs.

**2. More short technical review sessions**

Weekly cross-role reviews between frontend, backend, and AWS-related work would help teams stay aligned earlier and reduce integration gaps.

**3. Clearer testing or deployment guidance**

For cloud-oriented projects, having a shared test environment or at least a stronger deployment guideline would help students become more confident when moving beyond local development.

### Personal reflection in structured format

**Difficulty**

The most challenging part of the program for me was keeping frontend progress on track while expanding my understanding toward backend integration and AWS architecture within a limited timeline. Once the project pieces became more connected, the amount of knowledge I needed to manage grew quickly.

**How I addressed it**

I handled that by learning through the project itself: whenever CloudDoc required a concept, I studied that concept carefully, took notes, and applied it immediately. I also used workshops, mentor feedback, and team discussions to reduce trial-and-error time.

**Future direction**

After the program, I want to continue growing as a frontend developer, but in a way that is more tightly connected to data, APIs, cloud deployment, and system operations. I also want to improve how clearly I present technical ideas so I can collaborate more effectively in team environments.

### Personal reflection

I would still recommend FCAJ to friends because it offers a practical mix of cloud learning and project work. For me, the program significantly broadened my technical perspective and gave me a stronger foundation for future projects.

Overall, FCAJ was a meaningful internship experience. With even stronger documentation and technical alignment support, it could become even more effective for future cohorts.
